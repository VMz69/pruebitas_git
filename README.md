# Sitio de Prueba HTML + CSS

Este proyecto es un sitio web básico creado únicamente con HTML y CSS.  
Sirve como demostración o plantilla inicial para realizar pruebas rápidas de diseño o estructura.

## Páginas incluidas
- **Inicio:** página principal con texto de ejemplo.  
- **Acerca de:** información general de prueba.  
- **Servicios:** lista sencilla de servicios ficticios.  
- **Contacto:** formulario básico sin funcionalidad real.  

## Estilos
El archivo `style.css` aplica un diseño limpio y sencillo con colores azules, tipografía Arial y una estructura clásica de encabezado, contenido principal y pie de página.
